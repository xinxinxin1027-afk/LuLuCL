LuluCalendar is an open-source Android task and schedule planner built with Kotlin and Jetpack Compose.

Features include daily task planning, calendar views, recurring tasks, reminders, a Pomodoro timer, free-time analysis, local backups, multiple themes, and multilingual support.

LuluCalendar v0.0.1 defaults to Chinese and intentionally removes crash reporting, restore, home-screen widget registration, device-calendar sync, and event import features.
